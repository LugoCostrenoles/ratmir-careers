No paid hosting is required. To publish for free, use GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a new PUBLIC repository, e.g. ratmir-career.
3. Upload all three files from this folder to the repository root.
4. In repository Settings -> Pages, select "Deploy from a branch", branch "main", folder "/ (root)", then Save.
5. GitHub will show the public page URL (usually https://YOUR-USERNAME.github.io/ratmir-career/).

After the page is live, create a QR code pointing to that page URL. Test it from another phone or an incognito browser.

Privacy:
- The CV PDFs contain your phone number, email and home address. Anyone with the public page link can access them.
- Consider removing your home address from both CV PDFs before publishing. A city/region is usually enough for a public career page.
- The page itself intentionally does not display your home address.
